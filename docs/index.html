FAQ

Is withlook free?

Yes. withlook is free and open source (MIT). There is no account, subscription, or hosted backend — you bring your own model provider.

Can I use local models?

Yes. Use the opencode agent with a local model (Ollama, LM Studio, llama.cpp, vLLM), or point the OpenAI provider at any OpenAI-compatible local server via Settings → Base URL.

Which API models are supported?

Cloudflare Workers AI, OpenAI, and any OpenAI-compatible API. Models and agents are picked in Settings; keys stay on your machine.

Does it modify my project folder?

Not until you apply. Agents and the dev server run in an isolated git worktree (or a temp copy). Review the diff, then Apply to project, Commit, and Push.

Where does my code go?

Nowhere by default. withlook is local-first: projects, settings, and chat history stay on this machine. AI requests go only to the provider you configure.

What platforms are supported?

macOS (Apple Silicon) and Windows (x64) builds are available. Both are unsigned for now — see the download notes.
